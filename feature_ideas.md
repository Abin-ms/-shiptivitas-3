# Shiptivitas — Task 3: Feature Recommendations

## Analysis Summary

The Kanban Board feature was released on June 2, 2018.

Our SQL analysis shows:

- Average Daily Active Users before release: **3.63**
- Average Daily Active Users after release: **11.79**
- Increase in average DAU: **approximately 225%**
- Most cards have one or two recorded status changes, while a smaller number have more frequent changes.

These findings suggest that user engagement increased following the release, although they do not establish that the feature alone caused the increase. The DAU averages are calculated over days with recorded logins.

## Feature Idea 1: Smart Task Reminders

**Hypothesis:** Users will return to Shiptivitas more frequently if they receive timely reminders about unfinished tasks.

**Expected Impact:** Increased daily active users, improved task completion rates, and fewer forgotten tasks.

**What the feature is:** Add optional deadlines and notifications for pending tasks. Users can receive reminders when deadlines approach or cards remain inactive.

## Feature Idea 2: Task Progress Dashboard

**Hypothesis:** Showing users their progress will motivate them to return regularly and complete more tasks.

**Expected Impact:** Increased repeat engagement, better task visibility, and improved task completion.

**What the feature is:** Introduce a dashboard showing completed tasks, tasks in progress, overdue tasks, and weekly productivity trends.

## Feature Idea 3: Team Collaboration and Notifications

**Hypothesis:** Users will engage more frequently when they can collaborate on tasks and receive updates about their teammates' activity.

**Expected Impact:** Increased daily active users, more frequent card interactions, and improved team coordination.

**What the feature is:** Allow users to assign cards to teammates, add comments, and receive notifications when assigned tasks change status.

## Conclusion

The increase in daily active users after the Kanban release suggests an opportunity to build on the application's engagement. Smart reminders, progress tracking, and collaboration features are three ideas worth testing through future product experiments.
